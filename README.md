# Kata Nusantara Game

Aplikasi game edukasi berbasis Android Kotlin dan Jetpeck Compose. 

---

## 📱 Ringkasan Proyek
Kata Nusantara Game adalah aplikasi permainan interaktif yang dibangun menggunakan **Kotlin** dan **Jetpack Compose** untuk antarmuka (*UI*). Aplikasi ini memanfaatkan layanan **Firebase** serta **Google Gemini API** untuk menghadirkan pengalaman edukatif yang menarik.

## 🎮 Cara Menjalankan & Memainkan Game di HP

Jika kamu ingin mencoba dan memainkan game ini di HP Android kamu:

1. **Unduh File APK**
   * Masuk ke menu **Releases** di bagian kanan halaman repositori ini.
   * Unduh file `.apk` versi terbaru.

2. **Install Aplikasi di HP**
   * Buka file `.apk` yang telah diunduh di HP kamu.
   * Jika muncul peringatan keamanan, izinkan instalasi dari *Unknown Sources* (Sumber Tidak Dikenal).
   * Ikuti petunjuk di layar hingga proses instalasi selesai.

3. **Buka & Mainkan Game!**
   * Cari ikon **Kata Nusantara** di layar HP kamu dan selamat bermain!

---

## 🛠️ Untuk Pengembang (Developer)

Jika kamu seorang developer yang ingin ikut mengembangkan proyek ini:

1. Clone repositori ini (`git clone https://github.com/ShienyJocelyn/Kata_Nusantara-Game.git`).
2. Buka proyek menggunakan **Android Studio** (disarankan JDK 11 & SDK 36).
3. Buat file `.env` berdasarkan contoh `.env.example` untuk memasukkan `GEMINI_API_KEY`.
4. Tambahkan file `google-services.json` ke direktori `app/` untuk konfigurasi Firebase.
5. Sync Gradle dan jalankan di emulator/HP.
